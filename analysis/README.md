# Retinotopic Mapping for Widefield Imaging

A Python toolkit for retinotopic mapping in widefield imaging experiments.

## Setup

Install dependencies with [uv](https://github.com/astral-sh/uv):
```bash
uv sync
```

## Dependencies

This project uses [wfield](https://github.com/jcouto/wfield) for widefield data analysis.

> **Note:** Installing `wfield` via pip directly (`pip install wfield`) will attempt to install PyQt5, which may fail on some systems. Install it from the [GitHub repository](https://github.com/jcouto/wfield) instead.
